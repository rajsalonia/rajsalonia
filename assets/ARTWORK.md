## 2. Animated Engineering Headers (`banner-dark.svg`, `banner-light.svg`, `profile-hero-2026.svg`)
- **Dimensions:** 1200 × 280 pixels.
- **Typography:** Native high-contrast grotesque typography (`-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Roboto`, `Inter`) for maximum cross-platform rendering fidelity, paired with `ui-monospace` / `SFMono` for code symbols.
- **Architectural Topology Diagram:** 4 interconnected subsystem nodes representing a modern production stack:
  1. *Ingestion & Routing (API Gateway / FastAPI)*
  2. *Computation Engine (Optimization & AI)*
  3. *Persistence Layer (SQLite WAL / Models)*
  4. *Cloud & Delivery (AWS / Docker / CI)*
- **Motion & Data Packets:**
  - Self-contained SVG CSS keyframes (`flowRight`, `flowDown`, `flowLeft`, `flowUp`) driving dashed bus line offsets.
  - Smooth-interpolated glowing packet circles tracing data streams between processing nodes.
  - Refined terminal cursor blink (`1.05s steps(2, start)`).
  - Subtle status ring pulse on system availability indicator.
- **Reduced Motion:**
  - Full `@media (prefers-reduced-motion: reduce)` compliance stops all animations, sets terminal cursor to solid visible, hides traveling packets, and keeps lines crisp.
- **Zero Script Dependencies:** 100% pure SVG/CSS, validated with XML standard parsers.

## 3. Section Divider (`divider.svg`)
- **Dimensions:** 1200 × 20 pixels.
- Features a subtle technical baseline with an animated glowing pulse stream that glides across section boundaries.

## 4. Preservation of Existing Assets
- Original project vector art and historical assets are retained in the `assets/` directory.
- Contribution snake animation is generated by the scheduled repository workflow (`.github/workflows/contributions.yml`) and served from branch `output`.
